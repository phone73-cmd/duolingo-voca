# 나만의 단어장 v1.0.7

언어별 단어 등록, 발음 듣기, 학습 및 백업·복원을 지원하는 웹앱입니다.

- 실행: https://phone73-cmd.github.io/duolingo-voca/
- 앱 버전: v1.0.7 (설정 창에 표시)
- 배포: 기존 GitHub Pages 설정 사용

## 변경 내역

### v1.0.7 · 2026-10-20
- Safari 브라우저의 JSON·텍스트·엑셀 저장은 공유창을 열지 않고 파일 다운로드를 먼저 실행합니다. Safari 공유 저장에서 파일명만 담긴 불필요한 텍스트가 동반 생성되는 현상에 대한 대응입니다.
- 홈 화면에 설치한 앱은 기존 파일 공유 방식을 유지합니다. Chrome·Firefox·Edge 등 다른 브라우저의 공유 처리도 유지합니다.
- 파일명과 내용은 유지하고, Safari에서는 다운로드 목록 확인 안내를 표시합니다. 다운로드용 임시 URL은 비동기 저장 시간을 고려해 60초 뒤 해제합니다.
- 브라우저 구분, Safari 단일 다운로드·공유 미호출, 홈 화면 앱·다른 브라우저의 기존 경로와 파일 내용 보존을 모의 검증했습니다. 실제 Safari 다운로드 결과는 별도 확인이 필요합니다.

### v1.0.6 · 2026-10-20
- JSON 백업·텍스트·엑셀 저장의 공통 공유 처리에서 별도 제목 전달을 제거하고 파일만 전달합니다.
- 실제 파일명은 File 객체와 다운로드 파일명에 그대로 유지합니다. 공유 제목이 파일명뿐인 별도 텍스트로 저장되는 현상을 방지하기 위한 수정입니다.
- 파일만 전달되는지와 기존 파일명·내용 유지, 취소 및 다운로드 대체 처리를 모의 검증했습니다. 실제 iPhone 공유창의 파일 생성 동작은 별도 확인이 필요합니다.

### v1.0.5 · 2026-10-20
- 배움정원 방식으로 우상단 연결 상태·오프라인 사용 여부·안내 아이콘 3자리를 고정했습니다. 설정 버튼은 별도로 유지합니다.
- 안내 아이콘은 항상 표시하고, 새 버전이 준비되면 작은 주황 점을 표시합니다. 새 버전 여부에 따라 아이콘 위치가 이동하지 않습니다.
- 아이콘을 누르면 아래에 안내창을 열어 연결 상태, 오프라인 준비·사용 범위, 음성 제한, 현재 버전 및 업데이트 확인·적용을 표시합니다.
- 업데이트 적용 버튼은 대기 중인 새 버전이 있을 때만 안내창에 표시합니다. 업데이트 후 점과 적용 버튼이 사라져도 안내 아이콘과 새 버전 확인 기능은 유지합니다.
- 상태 변화로 안내창을 자동으로 열지 않습니다. 닫기 버튼·안내 아이콘·바깥 클릭·Escape로 닫을 수 있습니다.

### v1.0.4 · 2026-10-20
- 상단 업데이트 버튼을 항상 표시합니다. 평소에는 ‘새 버전 확인’, 대기 중인 버전이 있으면 ‘새 버전 적용’으로 표시합니다.
- 최신 여부, 오프라인, 다운로드 실패, 적용 지연 및 입력·학습 중 적용 제한을 버튼 옆에 안내합니다.
- 이미 설치 중인 서비스워커도 감시하고, 설치 완료 직후 대기 상태 전환을 놓치지 않도록 다음 작업 시점에 다시 확인합니다.
- 컨트롤러 변경 알림을 놓치는 경우에도 활성화 상태와 제한 시간을 확인하여 적용합니다.

### v1.0.3 · 2026-10-20
- JSON 백업에 시작 화면, 마지막 섹션, 음성 선택·속도·간격·뜻 읽기, 반복, 배경 농도를 포함하고 복원합니다. 즐겨찾기 색상도 백업 기준으로 복원합니다. 기존 백업도 계속 지원합니다.
- 전체 재생 시작 시 검색·필터를 해제하고 화면 순서 대신 단어 식별자로 강조합니다. 재생 중 검색·필터 변경 시 재생을 종료합니다.
- 서비스워커로 앱 화면과 엑셀 라이브러리를 저장합니다. 상단에 온라인·오프라인 준비 상태를 표시하며, 업데이트는 ‘새 버전 적용’으로 반영합니다. 캐시 교체 시 단어 데이터는 지우지 않습니다.
- 최초 온라인 접속 후 ‘오프라인 사용 가능’ 표시를 확인하면 연결을 끊고 앱을 다시 열 수 있습니다. 음성은 기기에 설치된 음성과 브라우저 지원에 따릅니다.
- Web Locks 지원 브라우저에서는 한 창만 편집하고 다른 창은 보기·내보내기 전용으로 사용합니다. 다른 창을 닫고 ‘최신 내용 열기’를 누르면 편집할 수 있습니다. 지원하지 않는 환경은 저장 버전 비교로 충돌을 감지하고 백업을 안내합니다.
- 기기 간 자동 동기화는 지원 범위에서 제외했습니다. 기기 간 데이터 이동은 JSON 백업·복원을 사용합니다. 기존 호스트 전용 동기화 코드를 제거했습니다.
- 설정 복원, 여러 창의 편집 제한·충돌 감지, 오프라인 앱·엑셀 캐시 및 기존 가져오기·데이터 보호 기능을 모의 검증했습니다. 실제 iPhone에서의 오프라인·홈 화면 실행 확인은 별도입니다.

### v1.0.2 · 2026-10-20
- 엑셀(.xlsx) 입력 양식, 현재 섹션 및 전체 단어 내보내기를 지원합니다. 전체 내보내기에는 언어·섹션 열이 포함됩니다.
- 여러 개 추가와 가져오기에 같은 입력 처리 및 확인 전 미리보기를 적용했습니다. 파일을 선택하는 것만으로는 저장하지 않습니다.
- 새 텍스트 형식은 `단어:`, `발음:`, `뜻:`, `예문:`을 사용합니다. 단어만 필수이고 쉼표·줄바꿈을 지원합니다. 기존 쉼표 형식도 선택할 수 있습니다.
- 모든 가져오기는 기존 데이터에 추가합니다. 같은 섹션의 단어+뜻이 같으면 건너뛰며 기존 발음·예문·외움·즐겨찾기를 덮어쓰지 않습니다.
- 엑셀은 기본적으로 현재 섹션에 추가합니다. ‘파일의 언어·섹션에 추가’를 켜면 앱에 있는 언어 탭을 찾아 섹션별로 추가하고 없는 섹션을 생성합니다. 없는 언어 탭과 중복 섹션명은 확인 대상으로 표시합니다.
- 정상 항목만 추가할 수 있으며 잘못된 항목은 확인 대상으로 남깁니다. 엑셀은 20MB, 50,000행·100열 이내를 지원합니다.
- 엑셀·텍스트 목록은 단어 편집용입니다. 외움·즐겨찾기·설정까지 복원하려면 JSON 백업을 사용합니다.
- SheetJS CE 0.20.3 mini를 vendor에 포함하여 외부 CDN 연결 없이 엑셀 파일을 기기에서 처리합니다. 라이선스는 vendor/SheetJS-LICENSE.txt에 있습니다.
- 코드 문법, 실제 XLSX 읽기·내보내기, 두 입력 경로, 중복·오류 처리와 v1.0.1 데이터 보호 기능을 검증했습니다. 실제 iPhone 화면 검증은 별도입니다.

### v1.0.1 · 2026-10-20
- 단어 이동 시 중복 항목의 빈 발음·예문·추가 표기와 외움·즐겨찾기 상태를 합칩니다. 내용이 충돌하면 별도 단어로 보존합니다.
- 설정의 전체 삭제 버튼을 ‘모든 데이터 초기화’로 명확히 표시하고 확인창에서도 삭제 범위를 안내합니다.
- JSON 백업의 단어·섹션·언어 탭·자료형·식별자 중복·연결 관계·색상 값을 검증합니다. 잘못된 백업은 기존 데이터를 변경하지 않고 거부합니다.
- 기기 저장 실패 시 화면에 백업 안내를 계속 표시하고, 서버 오류 안내가 기기 저장 성공을 잘못 표시하지 않게 했습니다.
- 초기화 시 배경 농도도 기본값으로 되돌립니다.
- 코드 문법 및 19개 모의 검증 항목 통과. 실제 iPhone 화면 및 음성 재생 검증은 별도입니다.

### v1.0.0 · 2026-10-20
- 버전 번호를 v1.0.0부터 새로 시작합니다.
- 백업 / 복원 창의 좌우 안쪽 여백을 20px로 통일했습니다.
- 파일 저장, 전체 단어 텍스트 저장, 파일 불러오기 버튼을 동일한 너비로 세로 배치했습니다.
- 닫기 버튼을 하단 오른쪽에 배치했습니다.
- 기존 저장 데이터 키와 백업 형식은 유지합니다.
