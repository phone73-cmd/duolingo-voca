# 나만의 단어장 v1.0.1

언어별 단어 등록, 발음 듣기, 학습 및 백업·복원을 지원하는 웹앱입니다.

- 실행: https://phone73-cmd.github.io/duolingo-voca/
- 앱 버전: v1.0.1 (설정 창에 표시)
- 배포: 기존 GitHub Pages 설정 사용

## 변경 내역

### v1.0.1 · 2026-10-20
- 단어 이동 시 중복 항목의 빈 발음·예문·추가 표기와 외움·즐겨찾기 상태를 합칩니다. 내용이 충돌하면 별도 단어로 보존합니다.
- 설정의 전체 삭제 버튼을 ‘모든 데이터 초기화’로 명확히 표시하고 확인창에서도 삭제 범위를 안내합니다.
- JSON 백업의 단어·섹션·언어 탭·자료형·식별자 중복·연결 관계·색상 값을 검증합니다. 잘못된 백업은 기존 데이터를 변경하지 않고 거부합니다.
- 기기 저장 실패 시 화면에 백업 안내를 계속 표시하고, 서버 오류 안내가 기기 저장 성공을 잘못 표시하지 않게 했습니다.
- 초기화 시 배경 농도도 기본값으로 되돌립니다.
- 코드 문법 및 19개 모의 검증 항목 통과. 실제 iPhone 화면 및 음성 재생 검증은 별도입니다.

### v1.0.0 · 2026-10-20
- 버전 번호를 v1.0.0부터 새로 시작합니다.
- 백업 / 복원 창의 좌우 안쪽 여백을 20px로 통일했습니다.
- 파일 저장, 전체 단어 텍스트 저장, 파일 불러오기 버튼을 동일한 너비로 세로 배치했습니다.
- 닫기 버튼을 하단 오른쪽에 배치했습니다.
- 기존 저장 데이터 키와 백업 형식은 유지합니다.
