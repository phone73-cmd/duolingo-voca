# 나만의 단어장 v1.0.2

언어별 단어 등록, 발음 듣기, 학습 및 백업·복원을 지원하는 웹앱입니다.

- 실행: https://phone73-cmd.github.io/duolingo-voca/
- 앱 버전: v1.0.2 (설정 창에 표시)
- 배포: 기존 GitHub Pages 설정 사용

## 변경 내역

### v1.0.2 · 2026-10-20
- 엑셀(.xlsx) 입력 양식, 현재 섹션 및 전체 단어 내보내기를 지원합니다. 전체 내보내기에는 언어·섹션 열이 포함됩니다.
- 여러 개 추가와 가져오기에 같은 입력 처리 및 확인 전 미리보기를 적용했습니다. 파일을 선택하는 것만으로는 저장하지 않습니다.
- 새 텍스트 형식은 `단어:`, `발음:`, `뜻:`, `예문:`을 사용합니다. 단어만 필수이고 쉼표·줄바꿈을 지원합니다. 기존 쉼표 형식도 선택할 수 있습니다.
- 모든 가져오기는 기존 데이터에 추가합니다. 같은 섹션의 단어+뜻이 같으면 건너뛰며 기존 발음·예문·외움·즐겨찾기를 덮어쓰지 않습니다.
- 엑셀은 기본적으로 현재 섹션에 추가합니다. ‘파일의 언어·섹션에 추가’를 켜면 앱에 있는 언어 탭을 찾아 섹션별로 추가하고 없는 섹션을 생성합니다. 없는 언어 탭과 중복 섹션명은 확인 대상으로 표시합니다.
- 정상 항목만 추가할 수 있으며 잘못된 항목은 확인 대상으로 남깁니다. 엑셀은 20MB, 50,000행·100열 이내를 지원합니다.
- 엑셀·텍스트 목록은 단어 편집용입니다. 외움·즐겨찾기·설정까지 복원하려면 JSON 백업을 사용합니다.
- SheetJS CE 0.20.3 mini를 vendor에 포함하여 외부 CDN 연결 없이 엑셀 파일을 기기에서 처리합니다. 라이선스는 vendor/SheetJS-LICENSE.txt에 있습니다.
- 코드 문법, 실제 XLSX 읽기·내보내기, 두 입력 경로, 중복·오류 처리와 v1.0.1 데이터 보호 기능을 검증했습니다. 실제 iPhone 화면 검증은 별도입니다.

### v1.0.1 · 2026-10-20
- 단어 이동 시 중복 항목의 빈 발음·예문·추가 표기와 외움·즐겨찾기 상태를 합칩니다. 내용이 충돌하면 별도 단어로 보존합니다.
- 설정의 전체 삭제 버튼을 ‘모든 데이터 초기화’로 명확히 표시하고 확인창에서도 삭제 범위를 안내합니다.
- JSON 백업의 단어·섹션·언어 탭·자료형·식별자 중복·연결 관계·색상 값을 검증합니다. 잘못된 백업은 기존 데이터를 변경하지 않고 거부합니다.
- 기기 저장 실패 시 화면에 백업 안내를 계속 표시하고, 서버 오류 안내가 기기 저장 성공을 잘못 표시하지 않게 했습니다.
- 초기화 시 배경 농도도 기본값으로 되돌립니다.
- 코드 문법 및 19개 모의 검증 항목 통과. 실제 iPhone 화면 및 음성 재생 검증은 별도입니다.

### v1.0.0 · 2026-10-20
- 버전 번호를 v1.0.0부터 새로 시작합니다.
- 백업 / 복원 창의 좌우 안쪽 여백을 20px로 통일했습니다.
- 파일 저장, 전체 단어 텍스트 저장, 파일 불러오기 버튼을 동일한 너비로 세로 배치했습니다.
- 닫기 버튼을 하단 오른쪽에 배치했습니다.
- 기존 저장 데이터 키와 백업 형식은 유지합니다.
